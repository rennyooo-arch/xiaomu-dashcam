为什么做这个

市面上的免费记录仪，录着录着弹广告，还把你的行踪往外传。这个反过来：连网络权限都没有，录像只存在你自己手机里，谁也拿不走。做它的人自己就是跑外卖的，知道司机要什么——上车自动开录、下车不用管，出事能拿出证据，就够了。

主要功能

  • 前后双摄同录（1080p），画中画可切换大小
  • 插电自动开录：车速达标自己开始；翻转手机两下停录；停车兜底自动停
  • 碰撞自动锁定 + 一键锁定本段，关键片段永不被覆盖
  • 一键导出证据包：视频 + 每秒 GPS 轨迹打包，给保险和警察刚刚好
  • 3 分钟分段循环，容量 32 / 64 / 128 / 256 GB 四档自选
  • 时间 / 位置 / 车速水印，横竖屏自适应，中英双语
  • 零广告 · 无账号 · 不联网

安装三步

  1. 点上方绿色按钮，下载 APK 文件
  2. 打开文件，系统提示时允许“安装未知应用”（这是安卓对商店外安装的例行提醒，装完可关）
  3. 打开 App，按提示允许相机、定位、麦克风，就能开录
