## 功能要点

- **前后双摄同录**（双录 1080p），画中画预览，主画面可切换
- **3 分钟分段循环录**，存储上限 32 / 64 / 128 / 256 GB 四档可选，满了自动覆盖最旧的未锁定片段
- **时间 + GPS 坐标 + 车速水印**，事后举证不用猜
- **一键锁定本段**（大按钮，盲按都行）+ **碰撞自动锁定**（灵敏度三档）
- **每段自带 GPX 轨迹文件**，路线和视频对得上
- **一键导出证据包**：视频 + 轨迹 + 片段信息打成一个 zip，直接发保险公司
- **前后片段分文件夹存放**，找文件不翻乱麻
- **自动化跑单**：插电待命、车速达标自动开录；翻转手机两下停录；停车兜底自动停（可选）
- **横竖屏自适应**，界面中英双语可切换
- **零广告、零账号、零内购**；不联网、不上传，录像只存在你自己手机里

## 系统要求

- Android 10（API 29）及以上版本
- 双摄同录需要手机硬件支持前后摄像头并发工作；不支持的机型可以使用单摄模式
- 建议预留足够存储空间（按所选循环容量档位）

## 安装步骤

1. 用手机浏览器打开本页，点上方按钮下载 APK 文件。
2. 下载完成后点开 APK。系统若提示"禁止安装未知来源应用"，进设置给浏览器（或文件管理器）打开"允许安装未知应用"的开关——这是安卓对商店外安装的例行提醒，装完可以关掉。
3. 点"安装"，装好后打开 App。
4. 首次打开会依次申请相机、麦克风、定位、存储权限，全部允许即可开始录（每项权限的用途见隐私政策：`privacy-policy-zh.md`）。
5. 把手机架稳、接上车充，就能上路了。

> 提示：本 App 目前不在应用商店上架，只能通过本页下载，这是测试期的临时分发方式，介意的话请等商店版。

## 测试期说明 · 欢迎反馈

这个 App 还在测试期，功能在持续完善，难免有毛病——你的手机型号上能不能双录、录久了稳不稳、碰撞锁定灵敏度合不合适，这些都得靠真实用车的人试出来。

**用出问题、觉得哪儿不好用、想要什么功能，都欢迎反馈：**

- 在本仓库的 [Issues](https://github.com/rennyooo-arch/xiaomu-dashcam/issues) 里留言（需 GitHub 账号）
- 或在小红书 / YouTube 发布视频的评论区留言

反馈时如果能带上这三样，修起来最快：**手机型号、安卓版本、出问题时大概在干什么**。App 设置里有一键"发送诊断日志"，把日志一起发过来就更好了（日志发送前会自动剔除坐标信息）。

先谢谢每一位愿意帮忙测试的朋友。好用的话，也欢迎推荐给身边开车的人。
